# Front-End Engineer — Job Specification Summary

* **Role**: Front-End Engineer (React Experience: 3–7 years).
* **Location**: Sandton, Johannesburg (In-Office).
* **Core Mandate**: High-performance React web applications integrated with AI/LLM-powered features (Chatbots, Summarisation, Document Understanding, AI-driven UI workflows).
* **Key Technical Requirements**:
  * React (Hooks, Context, component composition).
  * Modern JS (ES modules, async/await, DOM APIs), semantic HTML5, modern CSS3 (Flexbox/Grid).
  * Consuming REST / Web APIs and microservices (loading, error, state handling).
  * Automated testing discipline, WCAG accessibility, component reusability.
* **Nice-to-Haves**:
  * Streaming responses & token-level UI updates.
  * Vector search / RAG front-ends.
  * Design systems and shared component libraries.
